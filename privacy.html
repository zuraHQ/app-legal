Privacy Policy Privacy Policy Last updated: 23 jan 2026 This app helps users discover free items available near their location. Information We Collect We collect only one piece of information: ZIP code, entered by the user How the Information Is Used The ZIP code is used only on the user’s device to determine nearby free items. The ZIP code is not sent to any server. The ZIP code is not stored in a database. The ZIP code is not shared with any third parties. Data Storage All ZIP code data remains locally on the user’s device. We do not operate user accounts. We do not store personal data on external servers. Third-Party Services This app does not use third-party analytics, advertising SDKs, or tracking tools. Children’s Privacy This app does not knowingly collect personal information from children under the age of 13. Changes to This Policy If the app’s data practices change, this policy will be updated accordingly.
